# Deployment Screenshots

This folder contains screenshots documenting the successful deployment of a static website using Amazon S3 as part of Module 03 of the Codomax AWS Cloud & DevOps Internship.

## Screenshots

1. **S3 Bucket:** Shows the created S3 bucket and its uploaded `index.html` file.
2. **Static Website Hosting:** Shows the enabled S3 static website hosting configuration.
3. **Live Website:** Demonstrates the successfully deployed website accessible through the Amazon S3 website endpoint.

These screenshots provide evidence of the AWS configuration and successful website deployment.
